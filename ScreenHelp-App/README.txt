ScreenHelp — AI-Powered Screen Assistant
==========================================
Double-click ScreenHelp.exe to run.

NO INSTALLATION REQUIRED. Just run the exe.

FIRST RUN SETUP:
1. The app will open with a semi-transparent floating window.
2. Click the Settings button (top right).
3. Get a FREE API key from one of these:
   - Groq (Fastest, Free Llama 4 Vision): https://console.groq.com/keys
     -> Key starts with gsk_... -> paste in "Llama API Key"
   - Google Gemini (Free): https://aistudio.google.com/
     -> Paste in "Google Gemini API Key", choose 'gemini' provider

HOW TO USE:
  Press Ctrl+Shift+S  (or Ctrl+Shift+Space) from ANY window.
  ScreenHelp auto-captures your screen and instantly streams
  the answer — no clicks needed!

FILES:
  ScreenHelp.exe   — The app (run this)
  config.json      — Your settings (auto-created on first run)
  screenhelp.log   — Log file for troubleshooting

NOTES:
  - Run as Administrator for global hotkeys to work from all apps.
  - Window is semi-transparent by default (adjust the Ghost slider).
  - The window is hidden from Zoom/Teams/Meet screen sharing.
